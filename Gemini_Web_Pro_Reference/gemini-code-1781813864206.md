## 🛡️ The "Armor" (Execution & Capital Preservation Rules)

1. **The Entry Gate:** 0.45 - 0.60 Delta zone[cite: 5]. Bid/Ask spread must be < 10% under standard market regimes[cite: 5].
2. **The VIX Kill-Zone:** If VIX > 25.0, the maximum option spread threshold automatically tightens to < 2.0% to eliminate toxic slippage[cite: 5, 10].
3. **The Hard Floor:** A non-negotiable **0.25 Delta exit floor**. If a contract's delta drops below this baseline, the trade enters a mandatory "Kill Switch" state[cite: 5].
4. **Take Profit (TP):** Hard target at 50% premium expansion[cite: 5].
5. **Gamma Surge Automation:** The exact millisecond an open contract's Delta crosses **0.70**, the backend engages a one-way surge latch[cite: 3, 5, 6]. This activates a non-negotiable **10% Trailing Stop** calculated straight from the option's Peak High-Water Mark (HWM)[cite: 3, 5, 6]. Once latched, it remains active even if Delta falls back below 0.70[cite: 3].
6. **Gate 1b: Liquidity Gravity:** A mandatory execution check computed in `quant_math.py` that scans order-book depth asymmetry[cite: 5, 7]. A Bullish Call trade is immediately aborted if a "Supply Wall" is present (`Ask Size > 3x Bid Size`)[cite: 7]. A Bearish Put trade is aborted if a "Demand Wall" is present (`Bid Size > 3x Ask Size`)[cite: 7].

## 🔄 The 3-Stage Modular Assembly Loop

To bypass options chain discovery blindspots and data truncation on third-party APIs without causing token bloat, the workflow operates via a multi-stage modular handoff:

### Stage 1: The Macro Net (IBKR Workstation)
- **Operation:** Run the native IBKR MultiSort platform scanner across the S&P 500 universe[cite: 12].
- **Parameters:** Filter by high institutional volume baselines and sort for the lowest Implied Volatility / Historical Volatility (IV/HV) ratios[cite: 12]. 
- **Output:** A top-tier pre-sorted watchlist on the broker panel.

### Stage 1.5: The OCR Radar Gate (Claude Skill #1)
- **Operation:** User inputs an IBKR scanner screenshot or raw text table into Claude[cite: 12].
- **Protocol:** Claude executes `skill-ibkr-radar.md` to extract numeric positions, strip away misleading relative defaults, enforce the absolute Phase 12 volume ceilings, filter out earnings conflicts, and deliver the top 3 high-conviction finalists[cite: 3, 12].

### Stage 2: The MCP Deep Drilldown (Claude Skill #2)
- **Operation:** Claude targets the top 3 finalists using the **IBKR Model Context Protocol (MCP)** tool chain[cite: 2].
- **Protocol:** Claude directly queries the live desktop session (`get_price_snapshot`, `search_contracts`) to fetch zero-drift programmatic data points: live ATM IV, live 30-day HV, exact Contract OCC Symbols, and contract-level Greeks[cite: 2].
- **Handoff Output:** Claude outputs a raw, machine-readable JSON injection block mapping the deep broker telemetry.

### Stage 3: Kinetic Execution (Local Gemini CLI)
- **Operation:** The trader copies the Stage 2 JSON block and pastes it straight into the local Gemini CLI agent session.
- **Protocol:** The CLI agent ingests the high-signal parameters. It completely skips data discovery, validates the final absolute constraints (5M stock volume floor, 10K option chain volume baseline, spread parity, and Gate 1b Gravity checks), runs Sieve 3 (Fractal Squeeze via `quant_math.py`), and delivers an institutional-grade strategic verdict[cite: 1, 3, 7, 8].
